# Support

This project is open source. There is no hosted support desk.

| Need | Where |
| --- | --- |
| Install, DNS, backups, upgrades | [`docs/operations.md`](docs/operations.md) |
| How the apps fit together | [`README.md`](README.md) |
| Bug or patch | A GitHub Issue or pull request — see [`CONTRIBUTING.md`](CONTRIBUTING.md). Include the installer "System" block (or a screenshot) when you have it. |
| Security | [`SECURITY.md`](SECURITY.md) |

Firebase, Stripe, SendGrid, DNS, and VPS accounts are **yours**. Those vendors’ consoles are the right place for “my key does not work.”
